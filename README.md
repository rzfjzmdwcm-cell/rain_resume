# Rain Zhu CV Website

A bilingual static CV and portfolio website for a senior software engineer.

## Edit content

Most resume content lives in `index.html` inside the `profile` object:

- `profile.zh` controls Traditional Chinese copy.
- `profile.en` controls English copy.
- Update project links in the `projects` section.
- Replace `your.email@example.com` and the LinkedIn URL in the contact section.

## Preview

Open `index.html` directly in a browser, or serve the folder with any static file server.
